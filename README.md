## 使用说明
![主窗口图片](./readme/main.png "主窗口图片")

### 各按钮功能说明
- 工具栏
  - 打开文件：打开一个视频文件，支持avi、mp4、mkv、flv格式视频
  - 设置：打开设置窗口，可对粒子分析和显示进行设置，详见设置部分
  - 粒子分析：对视频进行读取、粒子识别及轨迹跟踪
  - 结果计算：计算粒子运动数据
  - 导出：将分析的结果导出，保存为视频，支持avi、flv、ogv格式
  
- 视频显示区：视频图像显示区域，主要的操作区域
  - 选择/移动：该按钮激活时可点击鼠标左键选中粒子，按住Ctrl键点击鼠标左键可选中多个粒子，按住左键拖拽可移动当前所选粒子
  - 添加粒子：激活该按钮后，在视频显示区内单击鼠标左键，可以添加一个粒子或改变一个已存在粒子的位置，详见操作说明
  - 裁切画面：激活该按钮后，可在视频显示区框选一个矩形范围，导出视频时仅会导出所选范围内的画面。如果当前已有选区存在，点击鼠标左键可以取消当前选区。切换到【选择/移动】按钮时，可以对选框进行移动
  - 合并粒子：未选中粒子时，点击该按钮会弹出对话框要求输入合并的粒子编号；选中多个粒子时点击按钮会将选中的粒子进行合并，详见操作说明
  - 显示/隐藏粒子：控制粒子的显示/隐藏
  - 显示/隐藏标签：控制标签的显示/隐藏
  - 显示/隐藏轨迹：控制轨迹的显示/隐藏
  - 显示/隐藏帧号：控制帧号的显示/隐藏
  - 显示/隐藏分析结果：弹出粒子运动数据弹窗，需要先进行结果计算后才会有数据显示
  
- 视频控制区：通过滑块控制显示视频的哪一帧，右侧数字显示格式为"当前帧-总帧数"
  - 播放：播放视频
  
- 筛选框：为空时显示所有粒子，输入内容后根据内容进行筛选，支持单个粒子和连续编号粒子筛选，空格或者英文逗号分隔，连续编号用"-"相连
  - 例1："1 3 5 7 9"将会筛选出编号为1,3,5,7,9的粒子，其它粒子将被隐藏
  - 例2："1-5 10,15"将会筛选出编号为1,2,3,4,5,10,15的粒子，其它粒子将被隐藏
  
- 状态栏：显示当前状态和进度

### 操作说明
1. 设置参数：点击设置按钮，设置分析模块各个参数
2. 打开文件：点击打开按钮，选择要分析的视频，确定后将自动进行视频加载和粒子运动轨迹分析
3. 调整参数：如果粒子识别效果较差，可以打开设置参数，调整分析参数，再次点击进行粒子分析，会根据当前参数重新进行粒子分析
4. 调整粒子：如果出现识别位置有偏差，或者同一粒子在视频不同帧中被识别成多个编号，或者部分帧没识别到目标粒子等情况，可以手动进行粒子调整
  - 移动粒子（仅对当前显示帧有效），在选择/移动按钮激活的情况下可对粒子位置进行调整
  - 添加粒子（仅对当前显示帧有效），在添加粒子按钮激活的情况下，在视频显示区单击鼠标左键，会弹出对话框，输入粒子编号后，可将粒子添加在鼠标单击位置；
    如果当前帧存在相同编号粒子，该粒子会移动到鼠标点击位置
  - 删除粒子（仅对当前显示帧有效），选中（一个或多个）粒子后，按下Delete键，会删除选中的粒子
  - 合并粒子（对视频所有帧有效），该功能主要用作同一个粒子在分析过程中出现多个编号，比如1-20帧该粒子编号是3，21-50帧粒子编号变为10，
    出现这种情况后粒子轨迹会分成两段，因此需要将3和10号粒子进行合并。合并后，如果某一帧中同时存在3、10号粒子，会保留3号粒子（所选粒子最小的编号）；
    如果只存在3或者10号粒子，会将其编号设置为3（所选粒子最小的编号）。具体操作如下：方法一，未选中任何粒子时，点击合并粒子按钮，
    弹出对话框要求输入要合并的粒子，规则与粒子筛选框一致，输入完后点击确定，粒子会完成合并；
    方法二，选中需要合并的粒子，点击合并粒子按钮
5. 调整显示效果：在【设置】-【显示】调整粒子、编号、轨迹、帧号的显示效果，详见设置说明；通过显示/隐藏按钮、粒子筛选框等可以调整显示内容
6. 计算运动数据：在【设置】-【分析】中设置比例尺参数，点击工具栏结果计算按钮（如果未设置比例尺，会弹出弹窗要求输入比例尺），会计算出粒子运动的速度、角度等数据， 
   计算完成后，点击【显示/隐藏分析结果】按钮，弹出计算结果弹窗，点击导出数据，会弹窗粒子筛选框，筛选规则与【筛选框】规则一致，点击【OK】后会将所选粒子数据导出
7. 导出视频：调整完成后，可以滑动滑块或点击播放按钮查看视频图像，点击【导出视频】按钮，可以将图像导出为视频，视频内容与视频显示区显示图像一致（如果有裁切图像框存在，导出视频只会有裁切部分）

### 设置说明
1. 分析参数设置：略，自行尝试
2. 显示参数设置：如下图
  - 颜色（粒子/标记/轨迹/帧）：点击颜色色块会弹出颜色设置框，颜色设置框可以设置多个颜色，双击每个颜色框可以弹出颜色选择器，
    设置多个颜色时，会按顺序依次显示各个颜色，比如，粒子颜色设置了红、绿、蓝三个颜色，编号为1、4、7...的粒子将显示红色
    编号为2、5、8...的粒子将显示绿色，编号为3、6、9...的粒子显示蓝色；粒子、标签、轨迹可以分别设置。
  - 大小/宽度（粒子/标记/轨迹/帧）：设置字体、粒子大小或者轨迹宽度
  - 与粒子颜色相同（标记/轨迹）：勾选后，将不能对标记/轨迹进行单独颜色配置，标记/轨迹的颜色与粒子颜色设置相同
  - 字体（标记/帧）：设置粒子编号或帧号的字体
  - 颜色随速度变化（轨迹）：设置粒子运动轨迹随运动速度变化（渐变色），点击速度颜色框，在弹出的渐变色设置弹窗中，上方颜色条为预览效果，
    下方列表中第一列的数字为对应颜色的位置（0-1），第二列为颜色，双击第二列中的颜色框，可以修改颜色，点击确定后完成渐变色的设置；
    当粒子运动速度小于最小速度时，显示颜色为渐变色最左侧颜色，当粒子运动速度大于最大速度时，显示颜色为右侧颜色，介于最大/最小速度是，颜色为渐变色中对应比例的颜色
  - 帧号位置：设置帧在画面的位置（左上/左下/右上/右下）
